# Opt-in Closing Sportifs

Funnel publicitaire Meta pour l'offre closing destinée aux jeunes sportifs.

- `optin.html` — page d'opt-in (prénom, email, téléphone), pixel Meta + Web3Forms
- `vsl.html` — page de remerciement / micro-VSL (35s), aucun lien de rendez-vous
- `video.mp4` — vidéo de la page VSL
- `guide.html` — guide complet de lancement de la campagne (domaine, pixel, ciblage, créas, conformité)

## Avant mise en ligne
1. Remplacer `META_PIXEL_ID` (dans `optin.html` et `vsl.html`) par l'ID réel du pixel.
2. Remplacer `WEB3FORMS_ACCESS_KEY` (dans `optin.html`) par une clé créée sur [web3forms.com](https://web3forms.com), ou basculer sur la capture native si hébergé via Systeme.io/ClickFunnels.
3. Déployer `optin.html`, `vsl.html` et `video.mp4` sur le nom de domaine propre (voir `guide.html`).
